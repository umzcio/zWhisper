  singleton by design; not a leak.

  bindings — none exist (digits are fixed chips, not Recorders). Non-issue.

  deep-copied in the tap; documented architecture §3.2 enabler. Accepted.

  sound player (`SoundEffects.swift:22-23`) — single-reader/serial-queue
  confined, documented. Accepted.

  latency, offline-first product stance.
- argmax-oss-swift vs argmaxinc/WhisperKit pin — resolved: argmax renamed the
  repo at v1.0.0; the pin URL is canonical.
